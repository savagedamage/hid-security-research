# Academic Papers

Curated summaries should record title, authors, venue/date, DOI or stable URL,
entry type, evidence label, limitations, and last-reviewed date. Initial
high-value work is represented as structured dataset records:

- BadUSB (Nohl & Lell, Black Hat USA 2014): `../../data/cves/poc-badusb-2014.yaml`
- Malboard (Farhi, Nissim, Elovici, Computers & Security 2019):
  `../../data/cves/research-malboard-2018.yaml`
- KNOB (Antonioli et al.): `../../data/cves/cve-2019-9506.yaml`

Future contributions should add independent summaries here without copying
copyrighted paper text.
