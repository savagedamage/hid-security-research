# Trusted Keyboard

Long-term high-assurance product research, not an implemented product.

The reference architecture is documented in
`../../hardware/architecture/secure-keyboard.md`: secure/measured boot,
non-exportable identity, challenge-response attestation, authenticated updates,
anti-rollback, locked debug, tamper evidence, radio-free baseline, reproducible
open firmware, and no cloud/privileged-driver dependency.

No security, certification, or production-readiness claim is made. Validation
requirements and hard trade-offs are explicitly listed in the architecture.
